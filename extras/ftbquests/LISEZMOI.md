# Chapitre FTB Quests (optionnel)

Copie `quests/chapters/aetheria.snbt` dans `config/ftbquests/quests/chapters/` de ton instance (FTB Quests pour 1.20.x), puis lance `/ftbquests reload`.

Les tâches s’appuient sur les advancements du mod et sur deux objets à fabriquer : le chapitre fonctionne donc sans code supplémentaire.
Le format SNBT peut varier légèrement selon la version de FTB Quests ; si le chapitre ne s’affiche pas, recrée-le dans l’éditeur en jeu en reprenant les mêmes tâches.
